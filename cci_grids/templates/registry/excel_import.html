Import Excel workbook

Download a blank import template, or use a registry export. New records are created only after you review and confirm. Existing records are never overwritten.

For hand entry, fill in Grids and Owners. Use a simple Session label such as session-1 for grids prepared together, and a different label for the next session. Labels belong only to this workbook. Leave the supporting Sessions sheet empty; the application creates internal keys automatically and leaves original shared defaults unknown.

Preparation dates accept YYYY-MM-DD, which defaults to 12:00 Europe/Stockholm, or a full timestamp with a UTC offset. Blank dates remain unknown.

New sample owners are created from the Owners worksheet. No login accounts or access grants are created. Unrecognised preparation operators remain unknown; the import audit records you as the importer.
